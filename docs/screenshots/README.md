# Gameplay screenshots

These are unedited emulator captures from this project. The bazooka image was
captured by Arthan; the other images come from development and regression tests.
Adventure and bazooka captures show v0.4/v0.4.1 presentation, the barrel and option
captures come from the exact v0.4.2 regression run, and the widescreen pause image
comes from the HUD correction pass included in v0.3 and later. Earlier captures
illustrate features retained in v0.4.2; they are not evidence of a new test run.

Images retain their original dimensions and pixels. README display sizing does
not alter the PNG files. No generated gameplay images or mockups are used.
