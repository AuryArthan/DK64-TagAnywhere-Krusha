## Donkey Kong 64 — Krusha + Tag Anywhere v0.4.2

Krusha as a sixth adventure character, with D-pad tagging, six-character tag barrels, a native bazooka, a vocal instrument attack, bananaports, boulder handling, and corrected widescreen presentation. Includes a persistent KRUSHA ON/OFF option.

### v0.4.2 fix
Prevents the inherited tree-tag origin warp while preserving ordinary airborne tagging. The exact game build passed 723 focused assertions; this is not exhaustive campaign or physical-console certification.

### Installation
Apply **DK64-TagAnywhere+Krusha.bps** to a clean, original **Donkey Kong 64 USA big-endian .z64** ROM. Tag Anywhere is included; do not stack this patch over another hack.
